# Personal Portfolio — Majd Sabbah

## Overview
An authentic, responsive personal portfolio website crafted from scratch without frameworks, templates, or UI libraries. Built to reflect professional software engineering standards, modern UI/UX design, and clean code architecture, while showcasing my skills, projects, and learning journey in Cybersecurity Engineering and Web Development.

## File Structure
- `index.html`: Main semantic document structure
- `style.css`: Custom responsive styling, theme variables, and layouts
- `script.js`: Dynamic theme switcher and event handling
- `assets/`: Media, profile photo, and other resources
- `README.md`: Project documentation

## Features
- **Sophisticated Aesthetic Design:** Custom color palette featuring charcoal, deep violet, soft lavender, and white, with refined shadows and a custom profile frame.
- **Mandatory JavaScript Feature:** Dynamic theme switcher (Dark/Light Mode) with persistent state via `localStorage`.
- **Event Lifecycle Architecture:** Event-driven interactions using event listeners, callback execution, and DOM/CSS updates.
- **Responsive Layout:** Built with native CSS Flexbox and Grid, paired with media queries for adaptation from mobile to desktop.

## Authorized Technologies
- HTML5 (Semantic markup)
- CSS3 (Variables, Grid, Flexbox, Transitions)
- JavaScript (ES6+)
- Git & GitHub (Version Control)
